# 数据保存与迁移

2026-10-10 本机原项目统计：全部采集文件真实内容 56,838,081 字节（54.21 MiB）；由于约 3.5 万个文件占用文件系统分配块，磁盘占用约 179 MB。原项目连前端依赖占磁盘约 255 MB。文件内容字节数与磁盘占用不是同一指标。

大部分内容来自逐人流程：原始排行榜 21.59 MB、断点 17.21 MB、逐人公开持仓响应 11.46 MB，合计约占历史采集内容的 88%。只分析股票名称和官方持仓人数时，无需这些文件。

最新热榜样本为 9 场入选比赛、90 条榜单记录、36 个不同证券。三个可复算聚合 JSON 共 **49,930 字节，约 50 KB**：

| 文件 | 字节 | 用途 |
|---|---:|---|
| `all-hot-stocks.json` | 43,672 | 比赛、股票名称/代码、官方持仓人数、榜内名次与源时间 |
| `catalog.json` | 5,289 | 已发现比赛的名称、人数、入选状态与时间 |
| `manifest.json` | 969 | 运行口径、完整性及失败状态 |

若记录数规模不变、每个交易日保存一份，按 252 天估算约 **12.6 MB/年**（十进制，不含 K 线、HTML、日志与原始响应）。这是当前样本规模的估算，比赛/股票增加时会增长；不是平台全量数据体积。

## 随 Skill 提交的历史样本

- `assets/sample-snapshots/2026-10-09_163213_822656/`：2026-10-09 官方热股聚合快照。
- `assets/sample-snapshots/2026-10-10_143434_119930/`：2026-10-10 取得的官方热股快照，官方源时间仍为 2026-10-09。
- `assets/sample-candles.json`：上述当前热榜中持仓人数合计前 10 只 A 股的腾讯前复权/不复权日线，截至 2026-10-09；保留实际取得时间与每只股票的来源链接。

三个核心 JSON 可离线重算比赛名单、热股排行与两个日期之间的变化。样本未取得完整四档，不能演示或补造加权共识分；`--hot-only` 明确禁用四档补采。JSON 日期用于历史复核，不标为本次实时数据。

## 哪些数据放 Git

适合放进此仓库：Skill 指令、脚本、配置、公开比赛登记表、少量聚合 JSON 样本。日常快照放在用户工作区，本地文件夹或独立数据仓库均可；每日提交前核对范围与日期，避免把工作区整体加入 Git。

不提交逐人名单原始响应、逐人持仓原始响应、成员检查点、请求日志、锁、缓存、前端依赖和本机绝对路径。这些文件可能含 `user_key`、`user_name`、`userid` 或用户页面地址；“公开可读取”不等于需要在公共 Skill 仓库重复分发。旧报告中的完整成员名单也要排除，不能只按文件是否位于 `raw` 判断。

此包的 `.gitignore` 排除默认运行目录、raw、检查点与请求日志。若要公开新聚合数据，仍检查实际 JSON 字段；把 `analysis.json` 中运行环境的绝对路径改为可复核相对路径，或仅提交三份核心快照并在接收环境重新生成报告。
