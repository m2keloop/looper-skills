# 双画面与裁切检查

只在处理“照片与插画”双画面海报，或需要从完成海报中拆出某个分区时阅读本参考。

生成前，用直白的语言指定每个分区及比例。例如：“3:4 竖版海报；上半部为照片，下半部为黑白干刷手绘；上下严格等高。”重复列出照片分区必须保持的项目：五官、发型、衣服、姿势、主体数量、构图、背景，以及允许做的调色。

裁切前，以完整高度查看生成的海报。如果分隔线正好位于每张图的中点，使用 `--split-ratio 0.5`；如果分隔线是已知的像素行，使用 `--split-y N`。裁切是纯几何操作，不能修复生成质量，也不能推断模型原本想要的分隔线。脚本默认执行自动方向校正和元数据清除；只在用户明确需要保留 EXIF/XMP/IPTC 等元数据时使用 `--preserve-metadata`。隐私模式禁止同时保留元数据。

如果所有海报的布局不完全相同，不要用一条命令裁切整个目录。应按正确几何参数分批处理，或将单张图片放入临时目录分别裁切，再把已验证的结果放进用户指定的集合目录。分享或同步结果时使用 `--privacy-mode`，使输出采用匿名文件名，且 `crop-manifest.json` 不保存原始文件名或绝对路径。
